복잡한 조건식 읽는 순서

  1. 기호 확인: 자바스크립트의 ^는 XOR, **는 거듭제곱.
  2. 입력 고정: n이 무엇인지 먼저 확인. 모르면 결과를 단정하지 않는다.
  3. 작게 계산: Math.imul(a, b)는 32비트 정수 곱, & 7은 마지막 세 비트만 남김.
  4. 분기 판단: 조건이 언제나 참/거짓인지 판단한 뒤, 조건 옆의 함수 호출에 부수 효과가 있는지도 따로 확인.
const n = 1771415611; // 이 번들의 검증값이 맞을 때
(Math.imul(n ^ 40, n ^ 40) & 7) == 1
// n은 홀수 → n ^ 40도 홀수 → 홀수의 제곱 & 7은 1
// 따라서 이 조건은 참

주의: 조건이 참이어도 그 앞의 x(...) 같은 호출은 실제 상태를 바꿀 수 있다. 조건식의 단순화와 함수 제거는 별개의 판단이다.
